# 🚀 Orbit – Social Media Platform

**Orbit** is a modern social media web application built with React and TypeScript. It provides users with an interactive platform to connect, share posts, engage with content, and manage their personal profiles.

The project focuses on building a responsive user interface, managing server-side data efficiently, and implementing reusable components with a clean and maintainable code structure.

---

## ✨ Features

### 🔐 Authentication

- User Registration.
- User Login.
- Form validation and error handling.
- Protected routes.
- Authentication state management.

### 📰 Feed & Posts

- Browse posts in an interactive feed.
- Create text-only posts or posts with images.
- Edit existing posts.
- Delete posts.
- Like and unlike posts.
- View post comments.
- Save posts for later.

### 💬 Comments & Interactions

- Add comments to posts.
- Display comments.
- Interact with posts through likes and comments.

### 👤 User Profile

- View personal profile information.
- Upload and update profile pictures.
- View personal posts.
- Browse saved posts.

### 👥 Community

- Discover suggested users.
- Search and filter suggested friends.
- Navigate through different feed sections.

### 🎨 User Interface

- Responsive and modern design.
- Reusable UI components.
- Interactive modals and dropdowns.
- Emoji picker integration.
- Consistent custom color palette and styling.

## 🛠️ Tech Stack

| Technology         | Purpose                                |
| ------------------ | -------------------------------------- |
| React              | Building the user interface            |
| TypeScript         | Type safety and maintainable code      |
| Vite               | Development environment and build tool |
| Tailwind CSS       | Styling and responsive design          |
| HeroUI             | UI components                          |
| React Router DOM   | Application routing                    |
| TanStack Query     | Server state management and caching    |
| Axios              | HTTP requests and API integration      |
| React Hook Form    | Form management                        |
| Zod                | Schema validation                      |
| React Icons        | Icons                                  |
| Emoji Picker React | Emoji selection                        |
